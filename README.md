# ✈️ Flight Management Application

A web-based Flight Management Application developed using **C# and ASP.NET Core MVC**.

I built this project to gain hands-on experience with .NET web development, MVC architecture, database integration, debugging, and version control using Git and GitHub.

## 🛠️ Technologies Used

- C#
- ASP.NET Core
- .NET
- MVC Architecture
- Entity Framework Core
- SQLite
- HTML/CSS
- Visual Studio Code
- Git & GitHub

## 📁 Project Structure

The application follows the MVC architecture:

- **Models** – Defines application data and entities
- **Views** – Handles the user interface
- **Controllers** – Handles application requests and logic
- **Migrations** – Manages database schema changes
- **wwwroot** – Contains static resources such as CSS and JavaScript
